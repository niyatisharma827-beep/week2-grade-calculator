# Student Grade Calculator

## Project Description
A comprehensive grade calculator that processes multiple students' marks, calculates grades with personalized comments, and provides class statistics.

## What I Learned
1. **Conditional Logic:** Using `if/elif/else` for decision making.
2. **Lists:** Storing and manipulating collections of data.
3. **Loops:** Using `for` and `while` loops for iteration.
4. **Error Handling:** Using `try-except` blocks to handle invalid inputs.
5. **Functions:** Organizing code into reusable modular blocks.

## Features
- Processes multiple students dynamically
- Calculates grades based on custom grading scales
- Provides personalized feedback comments
- Calculates class statistics (Average, Highest, Lowest)
- Formatted table output
- Input validation and error handling for all user inputs

## How to Run
```bash
# Navigate to project folder
cd week2-grade-calculator

# Run interactively

# Run with test input file
